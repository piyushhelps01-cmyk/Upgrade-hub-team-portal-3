UpgradeHub TEAM — v4.0.0 Branded UI Preview

Open UpgradeHub_UI_Preview.html in a modern browser. It is self-contained (CSS and logo images embedded) and is designed to work without a server.

Preview features: logo-branded dashboard, Tracker Hub entry points, work pulse, project focus, sample task Kanban, searchable 67-module catalogue, team directory, approvals, audit/security and operations mock screens. Main navigation, search and category filtering are interactive.

IMPORTANT: This is demo UI only. All sample names, counts, projects, approvals and events are illustrative; no backend/database is connected and changes are not persisted. Run the actual app using the setup instructions in ../README.md.
